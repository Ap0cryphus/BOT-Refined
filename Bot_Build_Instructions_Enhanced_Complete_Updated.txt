# Camfrog Bot - Enhanced Build Instructions

## Overview
This bot automates interactions with the Camfrog video chat platform, focusing on monitoring microphone states and managing user participation in chatrooms.

## Requirements
- Python 3.8+
- Windows OS (due to DXCam dependency)
- Required Python packages: 
  - opencv-python
  - numpy
  - pyautogui
  - dxcam
  - pywinauto (new requirement for UI automation)

## Installation Steps

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd CamfrogBot
   ```

2. **Install Python dependencies**
   ```bash
   pip install opencv-python numpy pyautogui dxcam pywinauto
   ```

3. **Create template images directory**
   ```bash
   mkdir templates
   ```

## Screen Capture Module Features

### DXCam Integration
- Uses DXCam for high-performance screen capture on Windows
- Falls back to PyAutoGUI when DXCam is not available
- Supports capturing specific regions of the screen

### Template Matching Functionality (New Feature)
This enhanced version implements OpenCV template matching to enable targeted monitoring:

1. **Template Loading**: Automatically loads all `.png`, `.jpg`, or `.jpeg` files from the `templates/` directory
2. **Template Matching**: Uses `cv2.matchTemplate()` to find UI elements in captured images
3. **Region-based Search**: Can search for templates within specific screen regions

### Template Matching Methods
- `find_template_in_image(image, template_name)`: Find a template in a given image
- `find_template_in_region(region, template_name)`: Capture a region and search for a template within it

## UI Automation Module Features

### New UI Automation Approach
A new module `ui_automation.py` has been added that uses pywinauto for direct UI element access:

1. **Direct UI Element Access**: Instead of OCR or template matching, the bot now directly accesses Camfrog's UI elements
2. **User List Extraction**: Efficiently extracts usernames from the user list container (ControlType List)
3. **Performance Improvement**: Significantly faster than image processing approaches

### Key UI Elements
- Chat Window ControlType: Pane(50033) / BoundingRectangle [l=1281,t=170,r=2299,b=1160]
- User List ControlType: List(50008) / BoundingRectangle [l=2303,t=141,r=2559,b=1160]
- Individual User Items: ListItem(50007) within the list

## Usage Example

```python
from screen_capture import ScreenCapture
from ui_automation import CamfrogUIAutomation

# Initialize capture module
screen_capture = ScreenCapture()

# Initialize UI automation for user list extraction
ui_automation = CamfrogUIAutomation()
if ui_automation.connect_to_camfrog():
    usernames = ui_automation.get_user_list()
    print(f"Found {len(usernames)} users:")
    for username in usernames:
        print(f"  - {username}")
