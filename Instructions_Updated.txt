# Camfrog Bot - Updated Instructions

## SECTION 1: PROJECT OVERVIEW
This document outlines the complete build instructions for a Camfrog chatroom bot that:
- Captures and processes chatroom data
- Performs moderation tasks
- Logs user information and behavior patterns
- Provides interactive features through triggers

## SECTION 2: CORE FUNCTIONALITY REQUIREMENTS
2.1 Display and Capture
- Capture right half of main monitor using DXCam
- Monitor chatroom header for topic changes
- Track menu options (Room List, Chatroom, Camfrog Time)
- Capture user list with pagination support
- Process chatroom feed including system messages and user messages

2.2 Data Collection
- Record all user information from chatroom
- Capture user attributes: speech patterns, biographies, gender identification
- Track user actions: topic changes, user joins/leaves, moderation events

2.3 Moderation Commands
- /unpunish <username>
- /unblockmic <username>
- /unban <username>
- /topic <topic>
- /watchlist <username>

## SECTION 3: BOT COMPONENTS AND ARCHITECTURE
3.1 Core Modules
- Screen Capture Module (DXCam)
- User Data Processing Module
- Moderation Command Handler
- Trigger Response System
- Audio/Text Communication Module

3.2 Technical Requirements
- Multi-monitor support
- Kill-switch for complete shutdown
- Silent switch for communication control
- Pagination handling for long messages (>425 chars)
- Multi-layered mic grab ladder:
  1) Camfrog PTT Key (VK_F10)
  2) CEF HWND WM_LBUTTONDOWN message post
  3) Chromium UIA button invoke
  4) Calibrated physical mouse hold (mouseDown)

## SECTION 4: TRIGGER SYSTEM
4.1 Trigger Types (Case insensitive, requires ! except for #1)
- kaekae/Kaekae - Responds to questions with contextual replies
- !chat - Turn on Chat Mode
- !chatoff - Turn off Chat Mode
- !shutup - Disable all bot communication
- !transcribe - Enable live room speech transcription
- !transcribed - Disable live room speech transcription
- !suppress - Opt user out of data collection
- !unsuppress - Re-enable suppressed user data
- !say "message" - Broadcast message via microphone
- !diss <username> - Roast target user with continuous 1-minute roasts
- !who is <username> - Generate user biography
- !info on <username> - Statistical profile (tone, usage patterns)
- !grabs [username] [duration] - Microphone grab statistics
- (-) - Next page trigger for long messages
- !idk <question> - Smart contextual response
- Moderation History Queries:
  who kicked [username]
  who blocked [username] / who unblocked [username]
  who banned [username] / who unbanned [username]
  who punished [username] / who unpunished [username]
- !happy - Set bot to happy tone (when chat mode on)
- !sad - Set bot to sad tone (when chat mode on)
- !mad - Set bot to angry tone (when chat mode on)
- !triggers - List all triggers

## SECTION 7: BUILD AND DEPLOYMENT
7.1 Environment Setup
- Python 3.x (recommended: Python 3.10)
- Camfrog application
- DXCam screen capture library
- Speech transcription capabilities (gemini-3.5-transcribe / Whisper)

7.2 Testing Dependencies (Required for Development and Testing)
The following additional packages are needed for testing and development:
- mouseinfo - For debugging screen coordinates during development
- pygetwindow - For window management during screen capture
- pymsgbox - For displaying message boxes in test environments  
- pyscreeze - For screenshot functionality during testing
- pytweening - For animation effects during testing

7.3 Installation Requirements
All required packages can be installed using pip:
```
pip install opencv-python pyautogui dxcam pytesseract numpy pandas sqlite3 requests speechrecognition pyaudio pillow mouseinfo pygetwindow pymsgbox pyscreeze pytweening
```

## SECTION 9: TESTING PROCEDURES
9.1 Testing Dependencies Installation
When running tests, ensure the following packages are installed:
```
pip install mouseinfo pygetwindow pymsgbox pyscreeze pytweening
```

9.2 Common Issues and Solutions
Issue: DXCam initialization fails in test environments
Solution: The system automatically falls back to PyAutoGUI implementation as specified in requirements

Issue: Missing dependencies during testing
Solution: Run the setup_bot.py script or manually install missing packages using pip

9.3 Testing Environment Setup
1) Create virtual environment: `python -m venv .venv`
2) Activate virtual environment: `.venv\\Scripts\\activate`
3) Install all dependencies: `pip install -r requirements.txt` (if exists)
4) Run tests: `python test_bot.py`
